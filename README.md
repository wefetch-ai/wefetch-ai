# gtinfetch — The GTIN resolver for AI agents · Know your transactions (KYT)

gtinfetch.ai is the resolver — the who, what, where of GTINs for agentic commerce. The GTIN fact checker for AI agents: any barcode, one call, the page under it.

MCP: `https://gtinfetch.ai/mcp` (streamable HTTP, stateless, no auth). One tool: `fetch_gtin(gtin, market?, believes?, receipt?)`.

Receipts: https://rco.wefetch.ai/ — every receipt wefetch issues lives here, and anyone can verify one.
