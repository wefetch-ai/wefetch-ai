## gtinfetch — The GTIN resolver for AI agents · Know your transactions (KYT)

gtinfetch.ai is the resolver — the who, what, where of GTINs for agentic commerce. The GTIN fact checker for AI agents: any barcode, one call, the page under it.

- **MCP:** `https://gtinfetch.ai/mcp` (streamable HTTP, stateless, no auth)
- **One tool:** `fetch_gtin(gtin, market?, believes?, receipt?)`
- **The plain read:** `GET https://gtinfetch.ai/01/{gtin14}` returns the signed record as JSON. Send `Accept: text/markdown` for the same answer as markdown.
